Simply type a request in the box on the SunaQ Find app page.

SunaQ will analyze that request, search for documents and present the information found in natural language.

SunaQ will correct search terms with obvious typos. Use quotes if a term should enter the query literally, for example if "tipo" is not a typo but really the term you are looking for.

Use /list [request] if you simply want a list of the documents found by SunaQ Find without generating an AI answer.

Search planning, Elasticsearch retrieval, deduplication and live Nextcloud ACL checks still apply in /list mode.
